# SM-G887N
**문제 상황**
**공식 Magisk (v30.7)은 이 기기에서 기본 설정 상태로는 작동하지 않습니다.**

## 1. 오딘 업로드중 Modem.bin Auth Err
* **무슨 일이 있었나?** Magisk가 부트 이미지를 패치하는 과정에서 실수로 `SignerVer02`라는 삼성 고유 서명을 삭제했습니다.
* **왜 'Modem'이라고 적혀 있을까?** 부트로더가 시그니처가 없어서 부트 이미지를 확인하지 못한 것입니다. 이 실패는 시스템 상태를 혼란스럽게 만들어, 다음 검사(모뎀)가 실패하고 잘못된 오류 메시지를 표시하게 만듭니다.
* **해결 방법** 수동으로 `SignerVer02` 서명을 패치된 `boot.img`에 다시 삽입했습니다. 이제 오딘이 파일을 받아서 완벽하게 플래싱합니다.

## 2. 부트 크래시 (`KDP_NS_PROT` 패닉)
* **무슨 일이 있었나?** 플래시가 성공적으로 끝난 후, 휴대폰이 시작 중에 강제 종료됩니다. 삼성의 커널 보안은 Magisk의 시작 파일(`/data/magiskinit`)을 ㅄ 으로 만듭니다.
* **해결 방법** Magisk가 정상적으로 부팅될 수 있도록 커널을 수정해 이 보안 검사를 우회했습니다.

## 요약
**공식 Magisk 30.7**을 사용했고 삼성의 필수 서명을 유지하고 커널 블록을 우회하기 위해 `boot.img`에 맞춤 수정을 추가했습니다.
